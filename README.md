## Tính năng chính

### 1. Trình giả lập Majmaj DX (Rhythm Game Engine)
### 2. Bộ sưu tập Mini-game
- **Neon Snake**: Rắn săn mồi phong cách lưới điện tử.
- **2048 Fusion**: Game ghép số logic.
- **Flappy Drone**: Trò chơi vượt chướng ngại vật cơ bản.
- **Tic-Tac-Toe AI**: Cờ Caro với thuật toán máy tính (Minimax).

## Kiến trúc & Công nghệ

- **Frontend Core**: React 18 (thiết lập qua Vite)
- **Ngôn ngữ**: TypeScript đảm bảo tính an toàn dữ liệu (type-safety) khi quản lý state và parser.
